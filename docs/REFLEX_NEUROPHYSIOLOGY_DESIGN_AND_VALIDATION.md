## 0. 符号与模型对齐

本文对齐本仓库的反射控制器：

```
y_m(t) = Σ_i β(i,m) · X_i(t) + b(m)
```

> 记号：设计矩阵用 `X`（旧版写作 `A = X*M`，`M` 为单位阵，已移除）。

- `β`：**26 特征 × 9 肌肉** 的**有符号**增益矩阵，按相位组（stance / swing）各一套。
- 特征行：
  - **1–9：`lCEN`**（归一化肌纤维长度）→ 生理对应 **肌梭 Ia**（长度/拉伸反馈）。
  - **10–18：`fATN`**（归一化 MTU 力）→ 生理对应 **高尔基腱器官 Ib**（力/负荷反馈）。
  - **19–26：关节角度/角速度** → 关节感受器 + 跨关节肌梭状态量。
- 9 块肌肉（列）：`hamstrings, bifemsh, glut_max, iliopsoas, rect_fem, vasti, gastroc, soleus, tib_ant`。
- `mask(i,m)=false` → 结构零（`β=0`，不进 CMA-ES）；`mask=true` → 自由参数，可正可负。

**记号**：`β(lCEN_j, m)` = 肌肉 j 的长度对肌肉 m 兴奋性的影响。
`>0` 兴奋（j≠m 即异名 Ia 兴奋）；`<0` 抑制（功能上接近交互抑制）；`=0` 无耦合。
`β(fATN_j, m)` 同理，但驱动力是**力**而非长度。

## 1. 定位：为什么是“设计依据 + 事后校验”，而不是“优化先验”

### 1.1 能真正作先验的东西很有限

把文献当“先验”去约束 `mask`/`β`，需要它给出**笃定的、可迁移的、定量或至少符号明确**的结论。
但本组文献能提供的很有限：

- **唯一较可辩护的先验**：Meunier 1993 中**未检出的单突触 Ia 兴奋**（如 `GM→Sol = 0/9`，且被
  Pierrot-Deseilligny 1981、Mao 1984 独立重复）。这最多支持“**这条快速兴奋性长度反馈接近零**”这一弱先验（§8）。
- **阳性连接的强度**不能作先验：PSTH 峰面积不是 EPSP 幅值，且只统计了显著阳性、坐位低阈值运动单位，
  与步行中的功能增益没有定量对应。
- **Ib 力反馈、交互抑制**的结论多为间接/推断（§1.2），不足以拿去定符号或剪枝。

### 1.2 多数实验结论是间接证据或推断（不够硬）

| 结论 | 实际证据性质 |
|---|---|
| 人步行存在 Ib 正力反馈 | **间接**：Grey 2007 靠“卸载 + 坡度解离”，作者自称 indirect；且仅 SOL、晚支撑相 |
| “传入贡献 SOL 支撑相 EMG ~50%” | Sinkjaer 2000 是**传入总贡献**，**非 Ib 特异**；作者倾向 group II |
| 支撑相“跖屈肌→背屈肌大抑制” | Petersen 1999 **没测到**，由相互抑制**推断**（“no direct evidence”） |
| Ib 反转的精确回路 | Pearson & Collins 1993 **仅摘要可得**（付费墙）；细节多为二手转述 |
| HAM→HFL 抑制（Geyer `L−`） | **显式假设**，髋屈肌运动神经元从未被采样 |
| 跨关节踝→膝 Ib | **本组无证据**，只有猫的线索 |

> 这些都不是“错”，而是**证据强度有限**。把它们当**讨论时的参照与解释资源**合适，当**优化约束**则过强。

### 1.3 正确用法：设计动机 + 事后核对

- **设计动机**：脊髓反射的原理（长度反馈、力反馈、交互抑制、相位调制）解释了**为什么框架要包含这些项**。
  这与 Geyer & Herr 2010 的做法一致——他也是“**力学/反射原理驱动设计 + 用 EMG/力学验证**”，
  而**不是**从神经生理参数辨识出模型。
- **事后核对**：本仓库用 **LASSO 稳定性选择辨识结构 + CMA-ES 优化增益**，是**数据驱动**。
  结果出来后，再与文献的**定性预期**对照（§7.3）：一致 → 加强生理合理性；不一致 → 可能是新发现或模型局限，
  诚实讨论。**方向是 数据 → 对照 → 解释**。

### 1.4 一句话

> 文献回答“**为什么这样设计框架**”和“**辨识出的结果像不像真实脊髓反射**”；
> 不回答“**这条增益必须是多少 / 这条必须为零**”。后者交给数据与优化。

## 2. 零基础心智模型：肌肉反射的“传感器接线”

> 本节用“传感器 + 反馈控制”的语言从零讲起，是理解 §3/§4 的地基。

每块肌肉装着**两种传感器**：

| 传感器 | 报告什么 | 接出的神经 |
|---|---|---|
| **长度传感器**（肌梭） | 肌肉被拉得多长、多快 | **Ia** |
| **力传感器**（腱器官 GTO） | 肌肉/肌腱上有多大张力 | **Ib** |

信号送进**脊髓**；脊髓里的**运动神经元**直接命令肌肉收缩。脊髓**不用等大脑**就能把传感器信号转成肌肉命令
——这就是**反射**，本质是一个**局部反馈回路**。

基本词：
- **同名** = 肌肉自己的传感器反馈给自己；**异名** = A 肌肉的传感器影响 B 肌肉。
- **正反馈 (+)** = 读数越大 → 肌肉越用力；**负反馈 (−)** = 读数越大 → 肌肉越被“踩刹车”（**抑制**）。
- **中间神经元** = 脊髓里的“中继/接力神经元”，信号经它再传，就多一个环节、慢约 1 毫秒，**符号可被它改写**。
- **单突触 / 双突触** = 传感器到运动神经元**直连（1 接头）**还是**经一个中继（2 接头）**。

### 两条接线规则（全部理解的地基）

**长度传感器 Ia：**
- 拉自己 → **兴奋自己**（正、快、直连）= 膝跳反射。
- 也兴奋一些**别的肌肉**（Meunier 1993 画的就是这张“异名兴奋”图）。
- 同时**抑制对手肌肉**（拮抗肌）= **交互抑制**，经一个中继，慢约 1 ms。
- → **同一个长度信号：对自己人 (+)，对对手 (−)。**

**力传感器 Ib：**
- **一定经中继**（从不直连）。
- **安静时**：力越大 → **抑制自己**（负力反馈，保护性）。
- **走路时（伸肌）**：翻转成 力越大 → **兴奋自己**（正力反馈，帮撑体重）。
- → 这个“安静抑制、走路兴奋”的翻转 = **reversal**。

## 3. Ib 力反馈（plain-language 版）

> 合并自原 §3 证据表与原 §7.1 机理详解；逐字引文/页码见 `_review_Ib_force_feedback.md`。

### 3.1 机理：为什么它编码“力”

**GTO 与肌纤维串联**（in-series）：肌肉只要产生张力（主动收缩或被动拉紧肌腱），就压迫其中神经末梢 → Ib 放电编码**力**。
对比：**肌梭并联** → 编码长度/速度（Ia）。Ib 对力极敏感（单个运动单位抽搐即可激活）。

**经典回路（安静时）= 自体抑制（负力反馈）：**
```
肌肉收缩 → 肌腱张力↑ → GTO → Ib → Ib 抑制性中间神经元 →（抑制）→ 自己/协同肌运动神经元
```
- **双突触，从非单突触**（Prochazka 1997：“entirely mediated through interneurons”）。
- 作用：力太大就刹住自己，防过度用力、补偿负载。
- Ib 中间神经元**多进多出**（接受多肌 Ib + Ia + 下行输入）→ **符号/增益可被中枢改写**（这是反转的结构基础）。

**反转（走路时）= 正力反馈：**
- 不是长出新通路，而是**同一 Ib 网络被运动状态（脊髓节律网络/伸肌半中枢）重新配置**。
- Pearson & Collins 1993：靶是**伸肌半中枢**，潜伏期 30–50 ms（远长于双突触节段反射 → 经运动网络）。
- 功能：收缩加载 GTO → Ib 兴奋 → **加强正在进行的收缩**（承重、柔顺腿）。

**为什么正反馈不发散（仿真关键）：**
- 环路增益 = **神经增益 K × 肌肉增益 M**。**K 长度无关、M 长度依赖**（力–长度曲线）；
  肌肉负载下缩短 → M↓ → **K·M 自限趋于 1**（Donelan 2009 实测）。
- **延迟反而稳定正反馈**（Prochazka 1997：加 40 ms 阻尼振荡）。
- 警告：对**不动/等长**负载可能失稳（“可能只存在于腿伸肌这类惯性负载肌肉”）。

### 3.2 学者怎么做实验（逻辑，不只是结论）

- **Pearson & Collins 1993（脊髓猫，仅摘要）**：可乐定诱发运动；刺激跖肌 group I 串，记录 MG。
  运动期兴奋、**同一串静息反而抑制** → 符号状态依赖；**振动跖肌（选择性 Ia）两者都不产生** → 锁定 Ib。
- **Donelan 2009（清醒行走猫）**：**去神经其它踝伸肌、孤立 MG**（测同源）；±25° 坡；估力/长度/速度 + 感受器模型预测 Ia/II/Ib；
  回归 `et=ec+ef`、`ft=M·et`、loop gain=K·M；**移动 peg 扰动**验因果。活动跟随**预测 Ib**（Ia/II 不变）→ 力反馈因果。
- **Prochazka 1997（人体 hybrid）**：真实肌肉 + **人工反馈回路**（传感器信号经滤波模拟 GTO/肌梭，中枢/传出全人工）。
  人为设增益 Gf 测负载补偿，Gf=2/3 仍稳定。**证明“控制律可行且稳定”，不是解剖证明**。
- **Grey 2007（人步行）**：±4% 坡，**晚支撑相**用踝执行器快速跖屈**卸载**，测 EMG + **直接跟腱力**。
  上坡**力↑、EMG↑** 但**踝位移↓、速度↓** → 力信号而非长度信号。**仅 SOL、间接**。
- **Sinkjaer 2000（人步行）**：卸载 + **CPN 阻滞**（排除交互抑制）+ **缺血阻滞**（排除 Ia）+ 麻醉（排除皮肤）。
  SOL EMG 降 ~50%、onset 64 ms。**但反应随支撑相力增大而减小**（与 Ib 预测相反）→ 作者倾向 **group II**。
  **证明“传入总贡献 ~50%”，不是 Ib/正力反馈**。

### 3.3 哪些笃定、哪些是推断（校验时心里有数）

| 结论 | 强度 |
|---|---|
| Ib 从非单突触、安静时自体抑制 | **较硬**（经典回路 + 多篇一致） |
| 运动中伸肌 Ib 反转为兴奋 | **较硬**（猫多篇；人间接） |
| 正力反馈稳定机制（K·M 自限、延迟助稳） | **较硬**（理论 + Donelan 实测） |
| 人步行 SOL 晚支撑相力反馈 | **中**（Grey 间接、仅 SOL） |
| “~50% 是 Ib 贡献” | **不成立**（Sinkjaer 是传入总贡献） |
| 异名 Ib（踝伸肌群内，猫跖肌→MG） | **中**（猫）；人体无全图 |
| 跨关节踝→膝 Ib | **弱/无证据** |

### 3.4 与 muscle-reflex 的联系（设计动机 + 校验点）

- **Geyer `F+`** = `prestimulation + 延迟、增益化的自身力`（同源 SOL/GAS/VAS），是**现象学控制律**，
  把 GTO 转导 + Ib 网络 + 募集**集总成一个延迟增益**；稳定性**隐式来自 Hill 力–长度曲线**；
  延迟 20/10/5 ms 是通用 H 反射延迟，比真实 Ib（猫 30–40、人 ~64 ms）短。
- **更生理的升级**（可选）：Prochazka 2002 `Ib(s)=KIb·F·(s+0.15)(s+1.5)(s+16)/[(s+0.2)(s+2)(s+37)]`，35 ms、激活门控。
- **设计动机**：框架里给伸肌（尤其 SOL/GAS）放**正力反馈项**是有脊髓原理依据的。
- **校验点**（§7.3）：辨识出的 `β(fATN)` 是否在 SOL/GAS 同源为正、支撑相为主、随负荷增大；符号是否状态依赖。
  VAS 正力反馈是**控制原理外推**（非生理证明）；跨关节踝→膝 Ib **无证据**，若出现应作探索性讨论。

## 4. 交互抑制（plain-language 版）

> 合并自原 §4 证据表与原 §7.2 机理详解；逐字引文/页码见 `_review_reciprocal_inhibition.md`。

### 4.1 机理：同一 Ia 传入，兴奋自己人、抑制对手

```
激动肌拉伸 → 肌梭 Ia ──┬──（单突触兴奋）──→ 自己/协同肌运动神经元
                       └──→ Ia 抑制性中间神经元（甘氨酸能）──（抑制，多 ~1 ms）──→ 拮抗肌运动神经元
```
- **双突触抑制**，比单突触兴奋多 **~0.9–1.0 ms**（Crone 1987 实测）；**甘氨酸能**（Petersen 1999：受体突变患者无抑制）。
- 功能：让拮抗肌别跟激动肌对着干。
- **调制结构**（增益为何不是常数）：**α–γ 联动**（下行同时驱动激动肌 α、γ 和 Ia 抑制性中间神经元）、
  **对侧 Ia 中间神经元相互抑制**（激动肌为何不被对手“误伤”）、**Renshaw 抑制**、**突触前抑制**。

### 4.2 是“长度驱动”还是“激活驱动”？——传入是长度，增益被激活调制

- **传入支是 Ia（拉伸）**：Crone 1987 **纯跟腱叩击**（零激动肌激活）就抑制 TA → **被动拉伸 alone 触发** → 纯激活驱动是错的。
- **但增益与激活相关**：γ 驱动使 Ia 放电 ≠ 纯长度；下行门控**先于 EMG 50 ms**；增益随激活分级（Shindo）。
- **修正**：Crone **未能重复** Tanaka/Shindo 的 tonic 背屈增强，且认为 Ia 中间神经元**不是**收缩平行“自然”抑制的主源
  （主源是长潜伏期 group I 通路）。
- → 建模上：**Ia 样长度/速度负反馈 + 相位依赖增益**（可加小量激活依赖项）；加 ~1 ms 延迟；两方向耦合。

### 4.3 学者怎么做实验（逻辑）

- **Crone 1987（静息，60 人）**：拮抗肌神经条件化 Sol/TA 的 H 反射。三重论证双突触 Ia：
  ① 纯皮支无效、阈值 ~0.6×M、**跟腱叩击重现** → 肌梭 Ia；② 对称法算出多 **0.9–1.0 ms** → 一个中继；
  ③ 弱叩击 10% + 弱电刺激 5% → **实测 24%（非 15%）** → 汇聚同一通路。**不对称：跖屈肌→TA 强于 TA→Sol**。
- **Petersen 1999（步行，17 人）**：匹配背景 EMG；**缺血阻滞**排除外周反馈、确认 group I 携带。
  背屈肌→跖屈肌 **摆动大/支撑缺如**（实测）；跖屈肌→背屈肌 **摆动小**；**支撑相方向没测到**（推断）。
- **Christensen 2001（步行，17 人）**：拉伸 TA + TMS 探皮层。**支撑相（TA 静息）单个大晚反应**（onset 76/92、peak ~110 ms，部分经皮层）；
  **摆动相小而变异**；**支撑相无短潜伏期 M1**，归因于交互抑制。**⚠️ Geyer 把这篇方向写反了**。
- **Tanaka 1974 / Shindo 1984（自主收缩）**：抑制随背屈增强、跖屈减弱，**与收缩强度平行**；提出 α–γ 联动与相互抑制。
- **Pierrot-Deseilligny 1981**：选择性缺血先阻 Ia 再阻 Ib → 分离双相；**符号规则 Ia 抑制拮抗、Ib 相反**（GM→TA Ib `+`）。

### 4.4 哪些笃定、哪些是推断

| 结论 | 强度 |
|---|---|
| 交互抑制是双突触 Ia、甘氨酸能 | **较硬**（Crone 延迟 + Petersen 药理） |
| 跖屈肌→TA 抑制存在且强于反向 | **中–高**（Crone、Pierrot 一致） |
| 背屈肌→跖屈肌 摆动大/支撑缺如 | **中–高**（Petersen 实测） |
| 支撑相“跖屈肌→背屈肌大抑制” | **推断**（Petersen 明言无直接证据） |
| 交互抑制是收缩平行“自然”抑制的主源 | **被 Crone 否定**（主源是长潜伏期 group I） |
| HAM→HFL 抑制 | **假设**（髋屈肌池未采样） |

### 4.5 与 muscle-reflex 的联系（设计动机 + 校验点）

- **Geyer `F−`（SOL 力→抑制 TA）模态错配**：真实交互抑制是 **Ia（长度）**驱动，Geyer 用**力**（Ib 样）；
  经典 Ib 符号相反（GM→TA Ib `+`）。故它是**功能性抽象**（支撑相 SOL 力与激活/长度相关），非已证明群 I 通路。
  **但“力负反馈”本身真实存在**（§5），所以 Geyer 用负力反馈**没错**，只是这条具体跨肌肉项是功能等效。
- **有据的抑制**是 Sol/GAS→TA 的 Ia 交互抑制，**从 GAS 引出更强**（GM→TA `−−` > Sol→TA `−`）。
- **Geyer `L−`（HAM→HFL）是显式假设**，增益来自双摆力学 → CMA-ES 消融候选。
- **设计动机**：框架里给拮抗肌对放**负长度反馈项**、并做**相位调制**，有脊髓原理依据。
- **校验点**（§7.3）：`β(lCEN)` 负成分是否出现在拮抗肌对、跖屈肌→TA 是否更强、是否摆动/支撑不同。

## 5. 三个常见误解澄清

1. **异名力反馈生理上可能吗？——可能，且存在，不是不可能。**
   Ib 中继神经元“多进多出”，A 的力传感器能影响 B。动物有据（猫跖肌→MG，都是踝伸肌）；
   实验集中在同名是**方法上好隔离**（Donelan 去神经孤立 MG），不是异名不存在。
   **但没有 Meunier 那样的人体异名 Ib 全图**（Ib 从非单突触，Meunier 的潜伏期 trick 不适用）；**跨关节踝→膝基本未证**。

2. **抑制只有长度负反馈吗？——不是。抑制至少三种来源：**
   - 长度 Ia → 抑制对手（交互抑制）；
   - **力 Ib → 安静时抑制自己（自体抑制）= 力负反馈，真实存在**；
   - 运动神经元自身活动 → Renshaw → 抑制自己/同伴（回返抑制，激活驱动）。

3. **运动时没有力负反馈吗？Geyer 用力负反馈是错的吗？——力负反馈真实存在，Geyer 没错。**
   走路时踝伸肌 Ib 翻成正，但力负反馈机制并未消失（安静时、其它肌肉/状态仍可为负）。
   Geyer 那条具体 `F−`（跖屈肌力→抑制 TA）是**功能抽象**（文献记录的跖屈肌→TA 抑制靠 Ia 长度，经典 Ib 符号相反），
   但“用负力反馈”这件事本身有生理根基。**对你优化增益来说，保留负力反馈项没问题。**

## 6. 任务普适性：增益为何随运动变（站立/步行/跑步/上下坡）

> **核心：区分“解剖连接（wiring）”与“功能表达（增益/符号/相位）”。
> 连接本身跨任务普遍存在（静息就在）；增益/符号/相位是任务依赖的。
> 步行特有的不是“通路”，而是“Ib 符号反转”和“反射的相位门控模式”。**

### 6.1 连接静息就在（不是步行特有）

- Ia 单突触兴奋：Meunier 在**坐位 <5% MVC**（近静息）测得 → 解剖布线，不依赖步行。
- Ib 自体抑制、交互抑制：静息即可测到（Crone/Shindo）。
- → **连接结构（mask）任务普适**；这正是 [`REFLEX_CONTROLLER_INTERPRETATION.md`](REFLEX_CONTROLLER_INTERPRETATION.md) §5.5
  “**结构可跨任务迁移、数值不行**”的解剖学基础。

### 6.2 增益是谁在拧？——好几只手一起拧（回答“CPG 天然 vs 大脑主动”）

把反射增益想成反馈回路上的**音量旋钮**，至少四只手：
1. **脊髓自己的运动模式（CPG/节律网络）**：进入“走路模式”就自动按相位调音量、甚至翻转 Ib 符号。
   **脊髓猫（无大脑）照样有 Ib 反转与相位调制** → 很大程度脊髓自带、无需大脑。最接近“CPG 天然编码”，但是**动态网络状态**，非固定查表。
2. **大脑下行**：按任务（站/走/跑、意图）调旋钮。证据：反射变化**先于 EMG 50 ms** → 上级提前命令。
3. **突触前抑制**：在传感器“输出端子”上直接静音/调小 = **那个音量旋钮本身**，脊髓和大脑都能拧。
4. **任务力学**：负载/长度/速度不同 → 传感器放电不同 → 有效反馈不同。

> 结论：**不是纯 CPG、也不是纯大脑，而是分层叠加**；每个任务差异里脊髓/大脑各占多少，尚未完全分清（Petersen 明说 unresolved）。

### 6.3 直接证据

- **Ia 增益 站立 > 步行 > 跑步**（Capaday & Stein）：
  - 1986（站 vs 走）：匹配刺激/EMG，站立 soleus H 反射**大至 3.5 倍**；支撑最大、摆动最小。
  - 1987（走 4 vs 跑 8 km/h）：跑步 EMG **2.4 倍**但 H 反射**反而更小**；H–EMG 斜率走陡跑平；归因突触前抑制；“自动增益补偿”防饱和/失稳。
- **Ib 贡献随负荷缩放**（上下坡实测）：Donelan 猫 ±25° **下坡 35%→平地 ~39%→上坡 54%**；Grey 人 ±4% 上坡力/EMG 同向↑。
- **交互抑制相位 + 任务门控**（Petersen）：背屈肌→跖屈肌 摆动大/支撑缺如；步行支撑相比匹配 tonic 更小。

### 6.4 按任务汇总

| 运动 | Ia 兴奋 | Ib 力反馈 | 交互抑制 |
|---|---|---|---|
| 静息/站立 | 存在；站立增益高 | **抑制**（自体） | 存在（弱、变异） |
| 步行 | 存在；支撑高/摆动低 | **反转为兴奋**，晚支撑 | 相位门控 |
| 跑步 | 存在；**增益下调** | 反转持续；精确跑步定量缺如 | 仍调制 |
| 快走 | 存在；随速度变 | 随负荷变 | 仍调制 |
| 上下坡 | 存在；调制 | **上坡↑、下坡↓** | 调制 |

> **建模含义**：`mask` 可跨任务迁移；`β` 数值**必须按任务/相位重新辨识 + CMA-ES 优化**。
> 诚实边界：人体数据多为步行；跑步特异证据来自 Capaday 的 Ia H 反射；上下坡 Ib 定量来自猫 + 人 ±4%。
> 不要声称有“跑步时人 Ib 贡献 X%”的精确数据。

## 7. 在论文中怎么用：设计出发点 + 事后核对

### 7.1 作为设计出发点（Introduction / Model 的动机）

把文献用作“**为什么框架长这样**”的论据，而不是“参数从哪来”。可这样组织叙述：

> 脊髓反射通过肌梭长度反馈（Ia）、腱器官力反馈（Ib）与交互抑制，把腿的力学状态直接映射为肌肉激活，
> 无需等待上级指令。Geyer & Herr（2010）证明这类反射足以自组织出人类步行力学与肌肉活动。
> 本研究以此为出发点，构建包含**长度反馈、力反馈、抑制项与相位调制**的反射框架；
> 但**具体连接结构与增益不预设**，而由人体测量数据经 **LASSO 稳定性选择辨识结构、CMA-ES 优化增益**确定。

要点：
- 长度反馈项 ← Ia 肌梭原理（Meunier；stretch reflex）。
- 力反馈项 ← Ib 腱器官原理与正力反馈（Prochazka/Donelan/Grey）。
- 抑制项 ← 交互抑制（Crone/Petersen）；**负力反馈也合理**（Ib 自体抑制，§5）。
- 相位调制 ← 反射增益的相位/任务依赖（Petersen/Capaday）。
- **明确声明**：这些是**设计动机**，结构与数值由数据辨识，避免被审稿人误读为“从神经生理参数赋值”。

### 7.2 作为事后核对（Discussion）

LASSO mask + CMA-ES β 出来后，与文献**定性预期**对照（§7.3）：
- **一致** → “辨识出的反射结构与已知脊髓反射原理一致，支持其生理合理性”。
- **不一致** → 不要强行附会；讨论可能是**新发现**（如数据驱动的某连接强于文献预期）、
  **模型局限**（集总/线性/缺皮肤前庭输入）、或**文献本身证据弱**（§1.2）。
- **方向**：数据 → 对照 → 解释。文献是**参照系**，不是**约束**。

### 7.3 可核对的具体预期清单

> “证据强度”指文献本身的硬度（§3.3/§4.4），用来决定核对时措辞的强弱。

**A. 长度反馈 `β(lCEN)`**

### 7.4 表述边界 / 避免误引（讨论时务必注意）

1. **不要写“Ib 力反馈贡献 SOL 支撑相 EMG ~50%”**：Sinkjaer 2000 的 ~50% 是**传入总贡献**（倾向 group II）；
   Ib 特异数值是**猫** ~30–39%（Donelan）；人体力相关性证据是 **Grey 2007（仅 SOL、晚支撑、间接）**。
2. **不要照抄 Geyer 对 Christensen 2001 的描述**：原文**支撑相大、摆动相小**（Geyer 写反）；
   可辩护的是“**短潜伏期 M1/Ia 成分**摆动有/支撑无”。
3. **Geyer `F−` 模态错配**：真实交互抑制是 Ia 长度驱动；经典 Ib 符号相反。力驱动抑制 TA 是功能抽象。
   但**力负反馈本身真实存在**，不要反过来说“力负反馈不存在”。
4. **HAM→HFL `L−` 是假设**（髋屈肌池未采样）；宜作消融候选，不要当已证明通路。
5. **跨关节踝→膝 Ib 无证据**；异名 Ib 仅在踝伸肌群内（猫）。
6. **支撑相“跖屈肌→背屈肌大抑制”是推断**（Petersen 无直接证据）。
7. **Pearson & Collins 1993 仅摘要可得**；细节须标注。
8. **β 是功能增益**（折合突触前/后调制、募集），不能与解剖 EPSP 幅值一一对应；
   文献百分比（如 Crone 14.9%）是**通路存在/不对称的证据**，**不是可移植的模型增益**。

## 8. 唯一可考虑作弱先验的部分（可选，非必须）

> 与 §1 一致：若你仍想注入一点先验，**只有这里较可辩护**，且是**弱先验**。其余交给 LASSO+CMA-ES。

**对象**：Meunier 1993 **未检出的单突触 Ia 兴奋**（兴奋性长度反馈的正成分）。

| Meunier 路路 | 检出 | 模型 `β(lCEN)` 正成分 | 置信度 |
|---|---|---|---|
| GM→Sol | 0/9 | `gastroc→soleus` | **较高**（Pierrot 1981、Mao 1984 重复） |
| DP→Q | 0/9 | `tib_ant→vasti` | 中 |
| DP→Bi | 0/8 | `tib_ant→bifemsh` | 中 |
| GM→TA / InfSol→TA | 0/6 / 0/6 | `gastroc/soleus→tib_ant` | 中–低（拮抗，预期负） |
| DP→Sol | 0/4 | `tib_ant→soleus` | 低（拮抗，预期负） |

**三条边界**：
1. **“未检出” ≠ “不存在”**：只测了单突触兴奋、n 小（4–25）、坐位低阈值、可能被突触前门控压低。
   它只否定“快速单突触 Ia 兴奋”，**不否定抑制或少突触兴奋**。
2. **不要设结构零（mask=false）**：那会连抑制一起删。拮抗肌对（gastroc/soleus↔tib_ant）**预期有负（交互抑制）**。
   若要用，应是**符号约束 `β≤0`**（禁正留负，保留参数、不降维），而非 mask=false。
3. **覆盖盲区不要碰**：以 hamstrings/bifemsh/glut_max/iliopsoas/rect_fem 为源或靶、腓骨肌相关路路，
   Meunier 几乎没测 → 交给数据，别因“表里没有”就置零。

> 务实建议：鉴于 §1 的判断，**可以完全不注入先验**，把上述预期全部放进 §7.3 作**事后核对**。
> 这样方法论更干净（纯数据驱动），也避免“先验过强”的审稿质疑。
